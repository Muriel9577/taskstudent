## 1. Аналіз задачі

Продукт: веб-застосунок для студента. Він збирає в одному місці предмети й завдання з дедлайнами та балами,
показує прогрес по кожному предмету у відсотках і набрані бали відносно прохідного.

Проблема: студенти розпорошують облік завдань по різних системах і не бачать, скільки ще треба для заліку.
Цільовий користувач: студент закладу вищої освіти.

## 2. Функціональні можливості, Хвиля 1 (5)

1. Реєстрація й вхід (одна роль).
2. Предмети: назва та прохідний бал.
3. Завдання: назва, опис, дедлайн, максимальний бал, статус (нове / виконано), отриманий бал.
4. Прогрес по предмету: відсоток виконаних завдань (кільце). 10 з 10 дає 100%, 5 з 10 дає 50%.
5. Бали по предмету: набрано N з прохідного M, показується смугою під кільцем.

Хвиля 2 (якщо вистачить часу): календар дедлайнів, нагадування, навчальні матеріали, темна тема.

## 3. Архітектура

Клієнт-серверний застосунок: Flask (REST API і статичні сторінки), SQLite, HTML/JS без зовнішніх бібліотек.

Шари:
- api (маршрути, перевірка, що користувач працює лише зі своїми даними)
- services (бізнес-логіка: прогрес, бали)
- db (схема та доступ до SQLite)
- static (інтерфейс: список предметів, сторінка предмета з кільцем)

## 4. Модель даних

User(id, email, password_hash, name)
Subject(id, user_id, title, pass_score)
Task(id, subject_id, title, description, deadline, max_score, status, score)

## 5. Послідовність реалізації

1. Каркас проєкту, схема БД, тести схеми.
2. Реєстрація й вхід.
3. Предмети (створення, редагування, видалення) із прохідним балом.
4. Завдання (створення, редагування, зміна статусу, внесення балу).
5. Підрахунок прогресу та балів (services) і кільце в інтерфейсі.
6. Тести, граничні випадки, виправлення знайденої помилки.
7. Code review, README, презентація.

## 6. Технічні ризики

- Предмет без завдань: ділення на нуль при підрахунку відсотка.
- Бал більший за максимальний або від'ємний.
- Користувач бачить або змінює чужі предмети й завдання (перевірка власника).
- Зберігання паролів (тільки хеші).
- Видалення предмета з завданнями (каскадне видалення).
- Прохідний бал більший за суму максимальних балів завдань.
- Округлення відсотка (наприклад, 1 з 3).
